**Key Analysis Points:**

### Prompt Template: Node 2 (Extraction & Detection Layer)

**Key Analysis Points:**

- Data flow consistency (state sharing, invariants)
- Caching strategy (key collisions, TTL, invalidation)
- Error handling & failures (exceptions, data loss)
- Policy application in this layer
- Performance & optimization

**Expected findings:** 5-15 per tier  
**Critical:** Flag TOCTOU races as CRITICAL if found

### Prompt Template: Node 3 (Cache, Events & Requests)

**Modules:** scan_cache.py, events.py, scan_request.py (680 lines)

**Key Analysis Points:**
- Cache safety (keys, TTL, invalidation, state consistency)
- Event bus reliability (listener failures, thread-safety)
- Copy semantics (shallow vs deep, shared references)
- Request validation & normalization
- Exception handling & silent failures
- Performance under load

**Expected findings:** 5-15 per tier  
**Critical:** Cache corruption and silent failures are high-priority
